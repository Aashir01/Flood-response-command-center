# Voice demo data

| File | Content | Source and license |
|---|---|---|
| `scripts/en.txt` | The spoken English script of the default demo briefing (`demo-sindh-2022`), 3,818 characters. | Our own text, generated by the Brain (`stitch_brain.api.voice.briefing_script` over the recorded-organs demo briefing) with `uv run python scripts/prerender_voice.py --build-scripts` on 2026-11-17. MIT, like the repo. Every sentence comes from demo organ outputs; nothing is live data. |
| `scripts/ur.txt` | The same briefing in Urdu, 3,740 characters. | As above. |

No audio is committed. Deepgram's terms do not clearly permit redistributing generated audio
(`docs/decisions.md`), so `scripts/prerender_voice.py` writes it to the git-ignored
`data/cache/voice/prerendered/` (or the `voice_cache` volume in Compose) at deploy time.
`uv run python scripts/prerender_voice.py --check-scripts` fails when the Brain's script no longer
matches these files.
